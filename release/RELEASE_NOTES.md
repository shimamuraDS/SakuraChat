# SakuraChat 0.1.2

- 普通聊天、隐私对话和加密局域网房间。
- 内置服务器公有 CA；网关 HTTPS、聊天连接 TLS，严格校验证书与服务器身份。
- 修复注册页获取验证码时控制器未定义的问题。
- 版本与更新仅提示 GitHub 新版本，不自动下载安装。

## 下载与运行

下载 `SakuraChat-0.1.2-windows-x64-portable.zip`，完整解压后运行 `appSakuraChat.exe`。无需填写服务器地址或安装 CA 到系统证书库。

**这是未签名 Windows x64 便携包**，可能显示“未知发布者”。请从本仓库下载并核对 `SHA256SUMS.txt`；哈希不等于数字签名。网关地址为 `https://47.105.85.58:8443`，内置 CA 仅含公有证书。

普通云端聊天不是端到端加密；隐私模式使用 Signal 协议。应用数据与密钥保存在当前 Windows 用户目录，不会随着 ZIP 升级而删除。旧测试版数据不自动导入；身份变化时请重新核对安全码。
