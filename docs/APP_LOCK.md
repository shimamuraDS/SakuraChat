# 持久应用锁

## 使用

登录后点击侧边栏齿轮 → 应用锁设置，设置两次相同的独立解锁密码。要求 8～128 个 UTF-8 字节，不建议复用账号密码。点击“立即锁定”或按 Ctrl+L 可手动锁定。启用前请妥善保存独立密码：本版本没有忘记锁密码的在线重置功能。

启用后，应用失去活动状态即锁定，连续 5 分钟无键鼠/触摸输入也会锁定。后台网络同步不会刷新输入计时。解锁失败累计 5 次后冷却 30 秒，之后失败逐步增加至最多 300 秒。密码推导在工作线程进行，不在 GUI 线程执行。

设置现在持久保存，按网关环境摘要和聊天 UID 隔离。再次登录或重启客户端后会读取设置并锁定；退出登录只清除进程内状态，不重置锁密码。旧版本只存在内存中的锁不会自动迁移，请在新版中重新启用一次。

本地设置位于 Qt AppLocalDataLocation/security/<环境摘要>-<UID>.lock，保存盐、校验值、版本和固定 KDF 参数的 DPAPI 密文，不保存原始密码。使用 QSaveFile 原子替换，禁止非原子直接写入回退；保存失败则不启用新锁。不使用这份设置加密聊天正文。

解锁后可在应用锁设置中选择“关闭此账号的应用锁”，再次确认后保存关闭状态；保存失败继续保留原锁。暂不提供直接修改密码，可先解锁并关闭，再重新设置。

设置损坏、版本不兼容或 DPAPI 无法解密时保持锁定，不自动删文件或创建新设置。请保留原设置并恢复原 Windows 用户配置或有效备份；单纯退出再登录不会解决问题。丢失密码/用户配置可能导致该本机锁无法正常解锁，启用前务必了解这一限制。不要将应用锁文件误当作聊天数据库删除。

## 安全边界

- 锁定时隐藏并禁用主页面，使用不允许 Escape/点击外部关闭的模态锁屏；C++ 读标记入口也检查锁定状态，避免生成新的已读标记。锁定前生成的回执仍可能继续同步。
- 云端收发同步继续进行，Token 并不因界面锁自动撤销。
- 使用系统随机源生成 32 字节盐，以 Qt PBKDF2-HMAC-SHA-256（600,000 次）生成校验值，再以 DPAPI 保护本地设置。参考 [Qt 文档](https://doc.qt.io/qt-6/qpassworddigestor.html) 和 [OWASP 密码存储说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。不据此声明 FIPS 认证。
- 本地消息正文和联系人 payload 另由 Windows DPAPI 保护，参见 [本地缓存保护](LOCAL_CACHE_PROTECTION.md)；查询元数据与历史明文残留不在该保护范围。应用锁密码不参与 DPAPI 解密，聊天对象仍驻留进程内存，不能抵御调试进程、修改客户端或截取已有屏幕内容的攻击者。QString/QByteArray 的副本也不能承诺完全擦除。
- 不会清空用户的系统剪贴板，不保证清除操作系统已有的任务预览或截图。它是防止旁人直接操作聊天界面的保护，不替代 Windows 锁屏、磁盘加密或未来的本地数据库加密。
- 有权限删除/回滚设置文件、修改客户端或调用同一 Windows 用户 DPAPI 的攻击者可能绕过此界面锁；它不是服务器强制的第二因素认证。失败次数与冷却仍为进程内状态，不保证跨重启限速；不要将其宣传为离线密码防破解系统。
- 本次只进行构建检查，未启动客户端验证窗口焦点、任务切换、休眠唤醒和超时场景。
