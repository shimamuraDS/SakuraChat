# 桌面通知隐私

入口：侧边栏齿轮 → 勾选“桌面通用提醒（不显示联系人或正文）”。默认关闭，切换后立即按当前聊天账号和网关环境原子保存，不需要点击服务端隐私设置的保存按钮。

开启后的通知只有固定标题 SakuraChat 和“你有新的聊天消息，请打开应用查看”。通知组件不接收正文、姓名、UID、头像或消息 ID，所以锁定前后都不显示这些内容。它仍透露正在使用聊天应用、收到新消息这一事实；不希望暴露时保持关闭。

只有成功合并的新实时私聊推送触发检查；重复消息、历史补拉、已删除标记对应的消息不提醒。应用在前台且未锁定时不弹桌面提醒。5 秒内至多弹一次，不排队补发所有提示。

设置存于 Qt AppLocalDataLocation/security/<环境摘要>-<UID>.notifications.json，仅包含版本和开关，不含凭据或消息。读取失败默认关闭；写入失败保持原设置并提示。退出登录隐藏托盘并停止新提示，重新登录恢复开关。

使用 QSystemTrayIcon，因此可执行程序增加 Qt Widgets 依赖并使用 QApplication；业务界面仍是 Qt Quick/QML，没有改成 Widgets UI。重新打包时需要包含对应 Qt Widgets 运行库。关闭主窗口仍按原流程退出，不实现关闭到托盘或后台常驻。

系统不支持托盘通知或系统禁用通知时不会保证弹出；未实现系统通知权限向导。通知不会自动解锁、跳到某个聊天或标记已读；用户需自行打开应用并解锁。

已交给系统的提示可能留在通知中心，退出、撤销消息或锁屏不保证收回；因为从一开始只有通用文案，不涉及撤回正文预览。没有实现姓名/正文预览开关、按联系人例外、静音时间段或声音设置。

本次只编译，没有启动客户端、显示通知、验证托盘/系统通知中心行为，也未修改系统通知设置。
