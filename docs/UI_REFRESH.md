# Kali 风格暗色界面与无边框窗口

## 聊天工作区布局

保持暗色冷蓝主题。按最新截图要求，左栏负责聊天、联系人、好友申请三种视图（申请数量徽标）；顶栏中央提供隐私、应用锁、刷新联系人，图标在上、文字在下，以整窗水平中心为基准。左栏底部退出登录。聊天顶部只保留会话详情开关，避免两套导航重复。

左栏选中态使用局部冷蓝模糊光晕、发光竖线与清晰图标，移除叠框边缘；顶栏悬停或对应弹窗打开时显示亮色图标与下划线。输入区采用提示箭头、局部柔光描边与矩形纸飞机发送按钮，空白消息时按钮禁用。仅对小范围高亮使用 QtQuick.Effects.MultiEffect，不做全屏模糊或持续闪烁。输入区总高 64、上下留白各 12（输入框约 40 逻辑像素），按文字实际高度和字体度量平衡上下内边距，单行与空占位文字居中，多行滚动。标题栏高度随工作区切换为 64/44，边缘缩放区域同步读取实际标题栏高度。

宽窗口显示右侧 ConversationInfo：联系人名称与 UID、客户端连接状态、当前加载消息数量、操作说明。明确区分客户端连接与对方在线状态，不生成虚假活动日志。窗口小于 1180 逻辑像素时自动隐藏右栏；切回聊天与恢复窗口宽度后按详情开关恢复。联系人卡片以独立徽标显示未读数量。

## 当前主题：石墨黑 / 冷蓝

按最新要求替换浅樱花粉主题。UiTheme.qml 集中定义背景、层级、边框、文字、强调色与语义状态色；不是 Kali 官方产品或主题复制。

- 登录、注册和重置使用双栏外壳，左侧为静态线框品牌面板，右侧为操作表单。
- 标题栏使用终端式标识与等宽字体，正文保留中文易读字体。
- 会话列表增加明确的选中态。无功能的顶部放大镜与更多菜单已移除，消息删除仍由右键菜单进入。
- 对话气泡、输入区、按钮、申请和隐私弹窗共用暗色主题；错误、成功状态保留独立语义颜色。
- 品牌线稿仅在尺寸改变时重绘；没有持续闪烁、无限位移动画或全屏模糊。
- 编译通过。此前离屏检查仅观察到进程存活，不能证明 QML 加载成功；随后实际运行发现主题 onAccent 命名被解释为信号处理器，已改为 accentText。桌面自动化没有取得窗口，真实窗口的视觉、缩放、交互及动画帧率仍待验收。

以下为此前控件与窗口实现记录；当前配色以上述 UiTheme 为准。

## 第二轮：结构与控件重做

- SakuraButton / SakuraField / SakuraDialog / SakuraComboBox / SakuraCheckBox 统一圆角、焦点、主次操作和弹窗过渡；页面不再直接依赖默认方角控件。
- 消息重写为内容自适应气泡，时间和状态位于气泡尾部。右键气泡打开删除菜单；重试仅在可重试时显示。去掉组件加载时的缩放弹跳，避免历史刷新干扰阅读。
- 侧栏使用 SakuraIcon 自绘线条，移除未实现通话和重复设置入口。输入区保留真实文本发送功能，并提示 Enter / Shift+Enter 操作。
- 表单使用统一输入框和品牌标志，隐私弹窗使用可滚动布局，黑名单操作行允许输入框收缩。
- Windows 11 通过 DWM 请求系统圆角。旧版 Windows 或不支持该能力的窗口环境不保证系统外轮廓圆角；不使用透明遮罩破坏窗口点击区域。
- 动画时长约 100～190 ms，主要用于按压、悬停、页面淡入和弹窗淡入缩放；尚未做帧率与高 DPI 性能测量。

本次界面调整保持登录、消息、隐私和应用锁协议不变。

- 主窗口移除系统标题栏，使用 WindowTitleBar.qml：拖动空白处移动窗口，双击最大化或还原，右侧提供最小化、最大化、关闭按钮。
- 窗口四边和四角通过 startSystemResize 请求系统缩放；最大化时禁用边缘缩放。
- 登录、注册和重置页共用主窗口，不再分别产生系统标题栏。资料、申请等 QML 弹窗保留业务标题。
- 使用奶白背景、浅樱花粉分区、玫瑰粉强调色和深灰正文；侧边栏和己方气泡使用深色文字以保持对比度。
- 应用锁仍然遮盖和禁用聊天内容，锁定页面提供独立窗口操作栏，不绕过解锁校验。

人工验收：登录/注册/重置切换，四边四角缩放，双击标题栏，还原后拖动，多显示器与 Windows 缩放，最小化恢复，应用锁，好友申请弹窗，长消息和状态显示。

这里的云端聊天不是端到端加密；配色和标题栏不改变安全边界。
