# 客户端安全与隐私配置

本轮保留云端聊天，未实现端到端加密。侧边栏齿轮提供搜索、申请、资料可见范围、已读回执开关和黑名单。

默认 development 模式仅允许本机回环 HTTP/TCP。生产模式在 config.ini 设置 `[Security] Mode=production`，使用 HTTPS 网关和 TLS 聊天端口；可通过 `CaFile` 指定应用专用 CA，不允许忽略证书错误。具体部署参见同级服务端仓库 `docs/SECURITY_IMPLEMENTATION.md`。

服务端需先备份数据库，再手动执行 `database/003_privacy.sql`；本次没有执行迁移。旧明文密码账号通过邮箱重置升级 Argon2id，聊天数据不删除。新密码限制为 8～128 个 UTF-8 字节，验证码为六位数字。

已增加按账号/环境持久保存的应用锁，使用方法和边界见 [APP_LOCK.md](APP_LOCK.md)。它隐藏界面并阻止新的已读标记，不使用锁密码加密聊天数据；退出登录不再重置应用锁。

已增加 Windows DPAPI 消息正文/联系人 payload 加密与事务转换，参见 [本地缓存保护](LOCAL_CACHE_PROTECTION.md)。查询元数据仍为明文，旧文件残留没有安全擦除；不是整库加密。

已接入消息删除按钮、确认流程及事件同步，见 [消息删除](MESSAGE_DELETION.md)，但尚未运行验证。

已增加新发消息的自动删除设置（默认关闭）：齿轮 → 自动删除设置，可选 24 小时、7 天、30 天。只对之后新发消息生效；关闭不取消已有期限。需要服务端迁移 005_message_retention.sql，详见服务端 docs/AUTO_DELETE.md，未运行验证。

已增加默认关闭的通用桌面通知，不包含联系人或正文，见 [通知隐私](PRIVATE_NOTIFICATIONS.md)。尚未运行系统通知验证。

尚未实现：多设备管理、应用锁密码恢复、整库加密和跨机密钥恢复。不能用此版本承诺设备丢失后的完整聊天数据保密。服务器也仍可读取未删除的云端聊天正文。

仅进行编译检查，未运行服务、客户端、数据库迁移或联调。完整安全属性尚未验证，不应直接作为生产安全验收结论。
