# 客户端安全与隐私配置

## 聊天模式与安全边界

SakuraChat 客户端当前提供三种不同的通讯模式，其安全边界与数据存储机制完全独立：

1. **云端普通聊天**：
   - 消息由服务端（ChatServer/MySQL）集中持久化并负责中继，**不提供端到端加密**；服务端可读取未删除的云端聊天正文。
   - 生产分发（`SAKURA_DISTRIBUTION`）强制要求 HTTPS 与 TLS；开发模式仅允许本机回环 HTTP/TCP。
   - 侧边栏齿轮提供搜索、申请、资料可见范围、已读回执开关、黑名单管理以及消息自动删除保留期设置。
2. **Signal 端到端隐私对话**：
   - 基于官方 libsignal 的 Rust C-ABI 桥接实现，提供真正的**端到端加密（E2EE）**。
   - 消息密文由客户端加密，服务端 GateServer 仅作为盲密文中继（`/private/v1`），完全无法解密正文。
   - 身份密钥、预密钥及会话状态以 DPAPI 加密存储于独立本地 SQLite 库。详见 [Signal 隐私对话模块](PRIVATE_CHAT.md)。
3. **加密局域网房间（LAN Chat）**：
   - 脱离云端账号系统，支持在可信局域网内创建临时加密房间。
   - 传输层使用 TLS 1.2+ 与动态生成的 EC P-256 证书保护，依靠房主分享的 SHA-256 指纹与 128 位口令核验身份。
   - 消息仅保留在内存中，退出房间或关闭应用即销毁，不落盘。详见 [加密局域网对话](LAN_CHAT.md)。

## 运行与分发环境策略

- **开发模式（Development）**：默认模式，仅允许本机回环（`127.0.0.1` / `localhost`）HTTP/TCP 连接。
- **生产模式（Production）**：在 `config.ini` 设置 `[Security] Mode=production`，或构建时开启 `SAKURA_DISTRIBUTION=ON`。强制使用生产 HTTPS 网关与 TLS 聊天端口；可通过 `CaFile` 指定应用专用 CA，严禁忽略证书校验。具体部署参见服务端 [安全实现与部署](file:///e:/SakuraChatProject/Server/docs/SECURITY_IMPLEMENTATION.md)。
- **便携分发**：与签名安装包采用相同的生产 TLS 策略，可通过 `SAKURA_CA_FILE` 内置公有 CA。Windows 代码签名是独立的发布者身份校验；未签名不代表允许明文连接。分发构建不读取旁置 `config.ini`，不会因修改配置降级为明文。

## 本地与账号隐私防护机制

- **应用锁（App Lock）**：
  - 按账号及服务环境持久化保存独立锁屏密码，使用 Windows DPAPI 加密保护。
  - 锁定期间立即遮盖聊天界面并拦截后台已读回执上报，连续输错 5 次触发指数冷却退避。详见 [应用锁说明](APP_LOCK.md)。
- **本地缓存保护（DPAPI）**：
  - 云端聊天本地 SQLite 缓存采用 Windows DPAPI 加密关键消息正文与联系人负载（Payload）。
  - 详见 [本地缓存保护说明](LOCAL_CACHE_PROTECTION.md)。注意：查询索引与元数据（UID、时间戳）仍为明文，非全盘/整库透明加密。
- **消息双向与单向删除**：
  - 界面提供消息长按/右键“删除”操作，支持“仅为自己删除”与“同时为对方删除”。
  - 接入协议 1044/1045 与 1046/1047 删除事件轮询，本地结合 SQLite `local_deleted` 标记与游标推进。详见 [消息删除与事件同步](MESSAGE_DELETION.md)。
- **自动删除（保留期限）**：
  - 侧边栏齿轮提供自动删除设置（默认关闭，可选 24 小时、7 天、30 天）。针对新发送消息有效，由服务端后台线程到期扫描销毁。详见服务端 [自动删除说明](file:///e:/SakuraChatProject/Server/docs/AUTO_DELETE.md)。
- **桌面通知隐私**：
  - 通用系统通知默认脱敏，不展示发信人昵称、UID 与聊天正文，仅提醒“收到新消息”。详见 [通知隐私](PRIVATE_NOTIFICATIONS.md)。
- **密码哈希与账号安全**：
  - 用户密码全面采用 libsodium Argon2id 单向哈希存储，注册与修改密码要求 8～128 字节，邮箱验证码为六位数字。

## 当前已知限制与未完成项

- 尚未实现：多设备并发在线与逐设备撤销、应用锁密码在线重置与找回、全盘透明加密（SQLCipher）以及跨设备密钥自动同步。
- 若客户端机器被植入恶意程序或遭受物理内存取证，无法保证绝对数据机密性。
- 完整安全属性依赖规范的生产环境配置与正式代码签名，请勿将测试版结论直接作为生产安全合规依据。
